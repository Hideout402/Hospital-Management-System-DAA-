# Hospital Management System

A four-member Data Structures and Algorithms (DSA) course project.

## Project Overview

The Hospital Management System will help manage patients, doctors, appointments, emergency cases, and billing through a shared web application.

## Technology Stack

- **Frontend:** React, TypeScript, and Vite
- **Backend:** C++
- **API:** Lightweight REST API
- **Database:** SQLite

## Main Modules

1. Patient Management
2. Doctor and Department Management
3. Appointment Management
4. Emergency Management and Billing

## DSA Learning Objectives

The project will demonstrate manual implementations of relevant data structures and algorithms in C++, including arrays, linked lists, stacks, queues, trees, searching, sorting, recursion, priority queues, and graphs.

## Development Workflow

1. Build the shared frontend foundation.
2. Develop each member's assigned frontend pages.
3. Implement the corresponding C++ backend and DSA logic.
4. Integrate the REST API and SQLite database.
5. Test the complete application.

## Team Collaboration

The team will use GitHub feature branches and pull requests to review and integrate changes safely.
